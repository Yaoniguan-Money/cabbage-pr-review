## 四图类型

| diagram_type | 布局 | 语义 |
|--------------|------|------|
| `architecture` | TB | base 单快照：模块层级、入口与主依赖 |
| `impact_overlay` | TB + changed subgraph | 变更波及模块，risk 着色 |
| **`global_compare`** | LR 双 subgraph | **全局架构 before/after 并排**：base 模块全景 vs head 模块全景，变更模块带 risk |
| `path_compare` | LR 双 subgraph | **关键路径**窄对比（与 global_compare 互斥语义） |

`global_compare` 节点须 `group=before|after`；变更波及模块须填 `risk`；可写跨组边。

## 质量 KPI 参数（CLI / JSON）

| 参数 | 说明 |
|------|------|
| `min_diagrams_count` | 结果中图表数量下限（示例默认 **4**） |
| `min_diagram_nodes` | 每种 diagram_type 节点数下限 |
| `require_path_compare_groups` | path_compare 须同时含 before/after 节点 |
| `require_global_compare_groups` | global_compare 须同时含 before/after 节点（默认 false 保兼容） |
| `max_arch_impact_jaccard` | architecture 与 impact_overlay 节点 id Jaccard 上限（1.0=不检查） |

示例：

```powershell
.\scripts\quality_regression.ps1 `
  -PrUrl "https://github.com/owner/repo/pull/N" `
  -MinDiagramNodes 2 `
  -RequirePathCompareGroups $true `
  -RequireGlobalCompareGroups $true `
  -MaxArchImpactJaccard 0.95
```

或使用 `scripts/quality_thresholds.example.json`（设置 `$env:QUALITY_THRESHOLDS_JSON`）。
