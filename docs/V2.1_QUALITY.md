# v2.1 质量 KPI 与回归说明

更新时间：2026-05-29  
前提：PR #1（v2 归零）、PR #2（质量修复）已 merge 至 `main`。

## 原则

- KPI **只读 `TaskResultSchema` 字段**（risks、diagrams、degradation_notes 等），不做业务关键词或路径规则判定。
- 阈值由 **CLI 参数或 JSON 配置文件** 传入，代码内不写具体 PR 编号或风险标题期望。
- 与 [V2_COMPLIANCE.md](./V2_COMPLIANCE.md) 一致：禁止在 Agent 主链路使用启发式 fallback。

## 指标定义（schema 驱动）

| 指标 | 来源字段 | 说明 |
|------|----------|------|
| `risks_count` | `result.risks` | 风险条数 |
| `degradation_notes_count` | `result.degradation_notes` | 降级说明条数 |
| `diagram_has_mermaid` | `result.diagrams[*].diagram_type` + `mermaid` | 三图是否各有非空 mermaid |
| `risks_evidence_coverage` | `result.risks[*].evidence` | 非空 evidence 占比 |
| `diff_atoms_count` | `result.diff_atoms` | 差异原子数 |
| `missing_info_count` | `result.missing_info` | 缺失信息条数 |

结构性失败规则（非业务）：

- `risks_count < min_risks`
- `degradation_notes_count > max_degradation_notes`
- 要求的 `diagram_type` 缺少 mermaid
- 有 `diff_atoms` 但 `risks` 为空，且 `missing_info` 与 `degradation_notes` 均未解释
