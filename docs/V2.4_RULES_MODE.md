# v2.4 纯本地规则模式

更新时间：2026-05-30

## 概述

第四种推理模式 `rules_only`（纯规则）：零 LLM、零 Ollama，由内置 YAML 规则包驱动审阅，结果以 **Markdown 报告** 展示（不含 Mermaid 四图、不支持 Rerun）。

## 与 v2.2「禁止启发式」的关系

| 范围 | 约束 |
|------|------|
| `backend/app/agents/` | 仍禁止 `RISK_KEYWORDS` / `_heuristic` 等 |
| `backend/app/rules/` | 允许**通用求值引擎**；业务 pattern 仅存在于 YAML |
| `backend/rules/default/` | 默认规则包（数据，非 Python 硬编码） |

### matcher-type（v2.5 Phase 2）

| 值 | 说明 |
|----|------|
| `regex`（默认） | 使用 `pattern-regex` 对 target 文本求值 |
| `ast` | 使用 `ast-query` + Tree-sitter 对新增 patch 片段求值；可选 `ast-filter`（`bare_except` / `wildcard_import` 等通用结构过滤器） |

AST 规则示例见 `packs/default/security.ast.yaml`（`python-bare-except`、`python-wildcard-import`）。

### DiffAtom 粒度（v2.5 Phase 2）

- 包级 `config.scope.split_patch_hunks`（默认 `true`）：多 `@@` hunk 的文件拆为多个 DiffAtom，逐 hunk 匹配
- 单 hunk 或无 `@@` 的文件保持单 atom（与 v2.4 行为兼容）


| 端点 | 说明 |
|------|------|
| `GET /api/llm-mode-options` | 含 `rules_only` 及 `visualization_mode` / `rerun_supported` |
| `GET /api/rules-meta` | Markdown 章节文案单源 |
| `POST /api/tasks` | `llm_mode=rules_only` 无需 Cloud/Ollama |
| `POST /api/tasks/{id}/rerun` | 规则模式返回 400 |

## 环境

- **无需** `DEEPSEEK_API_KEY` / Ollama
- 可选 `RULES_PACK_PATH` 指向自定义规则目录
- 内置默认包路径：`backend/app/rules/packs/default/`
